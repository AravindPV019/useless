### Project Description
Cook, Cooking, Cooked is an interactive web application that combines two fun experiences in a single platform. Users can either check how “cooked” they are for their upcoming examination or play a 3D cooking simulator.

### The Problem (that doesn't exist)
What if you are anxious about how much of your syllabus you can finish before your exam? This project provides a humorous way to find out how “cooked” you really are.

### The Solution (that nobody asked for)
The Are U Cooked? calculator estimates the user's exam preparedness based on their remaining days, modules, study hours, and workload. It also provides a humorous result and a certificate based on the final score.
The Can U Cook? module provides a 3D cooking challenge where the player prepares a burger through multiple interactive stages.

### Implementation
The project is implemented as a client-side interactive web application using HTML, CSS, and JavaScript.
The application consists of two major modules:
1. Are U Cooked?
This module is an academic preparation calculator. The user provides information such as:
- Number of days remaining
- Total number of modules
- Modules already covered
- Daily study hours
- Estimated hours required per module
- Panic mode
JavaScript processes these inputs and calculates a cookedness percentage based on the remaining workload and available study time. The result is displayed using different preparation levels, along with study requirements and humorous feedback.
The module also includes a certificate feature that displays the user's result.
2. Can U Cook?
This module is a 3D cooking game developed using Three.js. The player prepares a Gourmet Double Smash Burger through several stages:
1. Slicing – The player chops the required ingredients.
2. Cooking and Flipping – The player must flip the patty at the correct time.
3. Burger Stacking – Ingredients are placed on top of each other while maintaining the balance of the burger.
4. Chef Evaluation – The completed burger is evaluated by the chef.
The game includes progress tracking, coins, combos, timing mechanics, animations, success and failure conditions, and humorous chef reactions.
The Web Audio API is used to provide sound effects for different game actions.
